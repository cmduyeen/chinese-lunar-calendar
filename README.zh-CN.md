## 通过链接订阅

复制以下链接，在日历应用中选择“通过 URL 订阅”或“从 URL 添加”，粘贴链接并保存：

```text
https://raw.githubusercontent.com/cmduyeen/chinese-lunar-calendar/main/output/chinese_lunar_latest.ics
```

建议订阅链接，而不是下载 `.ics` 文件，以便日历应用获取后续更新。兼容 Google Calendar、Apple Calendar、Outlook 及其他支持 iCalendar 的应用。

## 日历内容

- 每日农历日期，包含闰月。
- 除夕、春节、元宵节、龙抬头、端午节、七夕节、中元节、中秋节、重阳节、腊八节和小年。
- 按中国标准时间计算的清明节。

日历使用中国标准时间（`Asia/Shanghai`），每年更新，覆盖未来 10 年。内容为农历日期和传统节日，不代表法定节假日或调休安排。
